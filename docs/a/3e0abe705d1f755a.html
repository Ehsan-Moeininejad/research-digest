شخصی‌سازی بدون احراز هویت کاربر با استفاده از سیگنال‌های مجاورت در ایربنبی

Personalization without user identity

Airbnb Tech تحلیل سطح: کاربردی انتشار: 1405/07/07 متن اصلی: 3 دقیقه امتیاز: 8.3/10
ایربنبی برای حل مشکل سردی مدل‌های ML در کاربران ناشناس، از سیگنال‌های مجاورت مکانی و محیطی بدون نیاز به تاریخچه کاربری استفاده می‌کند.

درباره چیست

تکیه نکردن به تاریخچه جستجو یا لاگین کاربر و استفاده از سیگنال‌های لحظه‌ای و موقعیتی برای شخصی‌سازی صفحات فرود و نتایج جستجو.

روش و اجزا

  • شناسایی کاربران ناشناس ورودی از کمپین‌های تبلیغاتی یا جستجوی ارگانیک
  • استفاده از سیگنال‌های مجاورت برای پیش‌بینی نیازهای اولیه کاربر
  • به‌کارگیری مدل‌های ML برای رتبه‌بندی نتایج جستجو و پیشنهاد مقصد بدون تاریخچه قبلی

کاربرد برای تیم

  • بررسی میزان ترافیک کاربران لاگین‌نشده ورودی از کانال‌های پدیدآورنده در پلتفرم
  • تست استفاده از موقعیت مکانی و سیگنال‌های بی‌سیم لحظه‌ای برای شخصی‌سازی صفحه فرود کاربران جدید

محدودیت‌ها

  • وابستگی به دقت و دسترسی به سیگنال‌های مجاورت و موقعیت مکانی کاربر
