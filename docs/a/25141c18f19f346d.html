خرید تبلیغات ایجنت‌محور در تلویزیون متصل با مدل Model Context Protocol

How Does Agentic Buying Work In CTV?

AdExchanger خبری / vendor تحلیل سطح: کاربردی انتشار: 1405/07/16 متن اصلی: 5 دقیقه امتیاز: 7.3/10
استفاده از ایجنت‌های هوش مصنوعی و پروتکل‌های یکپارچه‌سازی مانند MCP فرآیند خرید تبلیغات در کانال‌های تلویزیون متصل (CTV) را به داشبوردهای متمرکز منتقل کرده است.

درباره چیست

این مقاله از نشریه AdExchanger به بررسی نحوه کارکرد خرید ایجنت‌محور تبلیغات در بستر تلویزیون متصل (CTV) می‌پردازد. نویسنده با مدیران ارشد آژانس تبلیغاتی اینترمیدیا (InterMedia) و مدیران عامل شرکت‌های Vibe.co و Olyzon گفتگو کرده است تا وضعیت عملیاتی این فناوری نوظهور را تبیین کند.

مسئله و اهمیت

صنعت تبلیغات دیجیتال و کانال‌های CTV با پیچیدگی‌های زیادی در زمینه مدیریت پلتفرم‌های متعدد، گزارش‌گیری پراکنده و زمان‌بر بودن کارهای اجرایی مواجه است. سوال اصلی این است که چگونه می‌توان با استفاده از ایجنت‌های هوش مصنوعی، فرآیند تصمیم‌گیری و بهینه‌سازی کمپین‌ها را بدون از دست دادن کنترل انسانی تسریع کرد.

روی چه چیزی کار کرده‌اند

آژانس InterMedia با ترکیب پروتکل Model Context Protocol (موسوم به MCP) و یکپارچه‌سازی APIها، امکان مدیریت کمپین‌های CTV را از درون داشبورد Claude فراهم کرد. در این مدل، پلتفرم Vibe گزارش‌ها را به Claude منتقل می‌کند و ابزار ارکستراسیون Olyzon دسترسی به سایر پلتفرم‌های سمت تقاضا (DSP) و عرضه‌کننده (SSP) را از طریق APIهای قطعی مدیریت می‌کند تا تحلیل داده و اعمال تغییرات در یکجا انجام شود.

روش و اجزا

  • اتصال پلتفرم خرید CTV شرکت Vibe به داشبورد هوش مصنوعی Claude با استفاده از استاندارد بازبینی‌شده MCP
  • یکپارچه‌سازی لایه ارکستراسیون هوش مصنوعی Olyzon از طریق APIهای قطعی برای اتصال به پلتفرم‌های DSP و SSP
  • پرسش از ایجنت هوش مصنوعی برای استخراج گزارش‌های عملکرد کمپین، بررسی هزینه‌های ناشران و شناسایی روندهای رشد
  • بازبینی دستی تغییرات پیشنهادی توسط کارشناسان انسانی و تأیید نهایی پیش از اعمال در پلتفرم‌های اجرایی

یافته‌ها و اعداد

  • بیش از 1000 برند از ادغام MCP در پلتفرم Vibe استفاده کرده‌اند و خرید مبتنی بر این پروتکل سهم بزرگی از بودجه تبلیغاتی این پلتفرم را تشکیل می‌دهد.
  • بخش عمده‌ای از کمپین‌های قابل خرید (biddable) آژانس InterMedia پس از گذشت چند ماه به این جریان کاری ایجنت‌محور منتقل شده است.

نتیجه‌گیری

نویسندگان و مدیران صنعتی معتقدند که ایجنت‌های هوش مصنوعی نقش نیروی انسانی را از دکمه‌زنی و کار با ابزارها به قضاوت استراتژیک و نظارت دقیق تغییر می‌دهند. اگرچه استفاده از APIها نتایج قطعی‌تری نسبت به تعامل صرف ایجنت با ایجنت دارد، اما نظارت انسانی برای اطمینان از صحت اجرا همچنان حیاتی است و این ابزارها تا آینده نزدیک به استاندارد صنعت تبدیل خواهند شد.

کاربرد برای تیم

  • ارزیابی امکان استفاده از پروتکل MCP یا اتصال API برای یکپارچه‌سازی داشبوردهای تبلیغاتی و تحلیلی تیم Ads
  • تست قابلیت‌های ایجنت‌های هوش مصنوعی در متمرکز کردن گزارش‌گیری و پیشنهاد بهینه‌سازی کمپین‌ها
  • تعریف فرآیندهای نظارت انسانی (Human-in-the-loop) برای تایید خودکار یا دستی تغییرات بودجه و کمپین
  • بررسی چالش‌های یکپارچه‌سازی داده‌ها و استانداردسازی اصطلاحات میان پلتفرم‌های مختلف مارکت‌پلیس

محدودیت‌ها

  • فناوری MCP بسیار نوظهور است و استانداردسازی کامل آن زمان‌بر است.
  • یکپارچه‌سازی داده‌ها از منابع مختلف هنوز نیازمند عارضه‌یابی و تلاش‌های دستی برای استانداردسازی اصطلاحات است.
  • ابهام در مالکیت واقعی ایجنت‌ها و پلتفرم‌های زیرساختی وجود دارد.
