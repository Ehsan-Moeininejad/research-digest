## خلاصهٔ سریع: استفاده و امتیازدهی

- **خواندن:** کارت هر مطلب یک خلاصهٔ یک‌جمله‌ای و «کاربرد برای تیم» دارد؛ «خواندن بریف کامل» تحلیل یک‌صفحه‌ای مطلب را باز می‌کند.
- **فیلتر:** دکمه‌های دسته و جست‌وجو (عنوان، تگ یا نام تیم مثل `eCRM` و `Ads`).
- **امتیاز هر مطلب (از 10):** `0.35 × ارتباط با مارکتینگ + 0.65 × کیفیت + اثر ردهٔ منبع`. هر دو امتیاز را یک ویراستار AI پس از خواندن متن کامل می‌دهد.
- **شرط انتشار:** ارتباط حداقل {{ s.review.min_relevance }} و کیفیت حداقل {{ s.review.min_quality }}؛ در موارد مرزی مطلب رد می‌شود.
- **اثر ردهٔ منبع:** منبع اصلی {{ bonus1 }}، تحلیل معتبر 0، خبری / vendor {{ bonus3 }}.
- **لیدربورد:** {{ s.leaderboard.size }} مطلب برتر هر دسته با امتیاز حداقل {{ s.leaderboard.min_score }}؛ مطلب تازه فقط در صورت برتری در مقایسهٔ مستقیم وارد می‌شود.

## دایجست چیست

دایجست تحقیقات یک ایجنت خودکار است که برترین مقالات، پژوهش‌ها و آموزش‌های مرتبط با مارکتینگ را از منابع معتبر پیدا می‌کند، با دو مرحله بازبینی کیفی غربال می‌کند و برای هر مطلب منتخب یک بریف یک‌صفحه‌ای فارسی می‌نویسد. هدف این است که تیم بدون صرف وقت برای جست‌وجو، همیشه از مهم‌ترین تحولات حوزهٔ خود مطلع باشد.

**زمان‌بندی:** روزهای زوج ماه میلادی (2، 4، 6 و ...) ساعت 12:03 به وقت تهران روی سرورهای GitHub اجرا می‌شود و خروجی معمولاً تا ساعت 12:45 آماده است.

## استفاده برای اعضای تیم

- **مرور سریع:** خلاصهٔ یک‌جمله‌ای و «کاربرد برای تیم» هر کارت نشان می‌دهد آیا مطلب ارزش خواندن بریف کامل را دارد.
- **مطالعهٔ عمیق:** «خواندن بریف کامل» این بخش‌ها را دارد: درباره چیست، مسئله، روی چه چیزی کار کرده‌اند، روش، یافته‌ها و اعداد، نتیجه‌گیری، کاربرد برای تیم و محدودیت‌ها.
- **فیلتر:** دکمه‌های دسته فیلتر می‌کنند. جست‌وجو روی عنوان، کاربرد، تگ‌ها و نام تیم‌ها (`Ads`، `Affiliate`، `eCRM`، `Engagement`، `Data`، `Product`، `Leadership`) کار می‌کند.
- **مرجع همیشگی:** تب «لیدربورد» برای آشنایی اعضای جدید یا مرور پایه‌ای یک حوزه مناسب است.
- **آرشیو:** منوی کشویی کنار جست‌وجو، دایجست هر نوبت گذشته را باز می‌کند.

## جریان کار هر نوبت

1. **جمع‌آوری:** خواندن همهٔ منابع برای مطالب {{ s.leaderboard.window_days }} روز گذشته؛ فید خراب خودکار ترمیم می‌شود.
2. **غربال اول:** امتیاز «ارتباط با مارکتینگ» و «کیفیت» از روی عنوان و چکیده؛ فقط مطالب تازه امتیاز می‌گیرند و نتیجهٔ بقیه از حافظه خوانده می‌شود.
3. **غربال دوم:** متن کامل حدود {{ s.selection.shortlist_size }} کاندیدای برتر {{ s.selection.lookback_days }} روز اخیر را یک ویراستار سخت‌گیر (AI) می‌خواند. اگر مطلبی گزارش کار دیگران باشد، منبع اصلی جایگزین آن می‌شود.
4. **انتخاب:** {{ s.selection.target_articles }} مطلب برتر که قبلاً نمایش داده نشده‌اند، با پوشش متوازن دسته‌ها.
5. **بریف‌نویسی:** یک بریف یک‌صفحه‌ای فارسی برای هر مطلب.
6. **لیدربورد:** رقابت مطالب منتخب با برترین‌های هر دسته؛ دسته‌های ناقص از برترین مطالب {{ s.selection.lookback_days }} تا {{ s.leaderboard.window_days }} روز گذشته پر می‌شوند.
7. **ارزیابی منابع و انتشار:** به‌روزرسانی کیفیت منابع، ساخت وب‌سایت و ارسال ایمیل.

## منابع: انتخاب، رده‌بندی و به‌روزرسانی

### ردهٔ اعتبار

| رده | تعریف | اثر در انتخاب |
| --- | --- | --- |
| 1. منبع اصلی | پژوهش، گزارش آزمایش‌های خود شرکت‌ها، اعلان رسمی پلتفرم‌ها | {{ bonus1 }} امتیاز؛ مجاز در لیدربورد |
| 2. تحلیل معتبر | دانشکده‌های کسب‌وکار، مشاوران، نویسندگان شناخته‌شده | بدون تغییر امتیاز؛ مجاز در لیدربورد |
| 3. خبری / vendor | پوشش خبری و محتوای شرکت‌هایی که محصول می‌فروشند | {{ bonus3 }} امتیاز؛ حداکثر {{ s.selection.max_tier3 }} مطلب در هر نوبت؛ ممنوع در لیدربورد |

**ترجیح منبع اصلی:** در غربال دوم بررسی می‌شود که آیا مطلب گزارش پژوهش، آزمایش یا نظرسنجی شخص یا سازمان دیگری است. اگر هست، منبع اصلی از لینک‌های متن پیدا، دانلود و بازبینی می‌شود و در صورت تأیید جای مطلب واسطه را می‌گیرد. در بریف عبارت «پوشش از طریق ...» دیده می‌شود.

### رشد و نگهداری خودکار

- **کشف منابع اصلی:** دامنه‌ای که در 30 روز گذشته حداقل {{ s.sources_health.primary_discover_min }} بار منبع اصلی مطالب دیگر بوده، نامزد افزودن به‌عنوان ردهٔ 1 می‌شود.
- **پیشنهاد هفتگی:** هر هفته تا {{ s.sources_health.scout_max_new }} منبع جدید، با اولویت منابع اصلی و دسته‌های کم‌منبع. سایت‌های خبری، vendor و تجمیع‌کننده پیشنهاد نمی‌شوند.
- **دورهٔ آزمایشی:** منبع جدید ابتدا امتیاز می‌گیرد ولی منتشر نمی‌شود. بعد از {{ s.sources_health.probation_min_items }} مطلب، با میانگین کیفیت حداقل {{ s.sources_health.probation_promote_avg }} فعال و با میانگین زیر {{ s.sources_health.probation_reject_avg }} رد می‌شود.
- **سلامت:** فید خراب ترمیم می‌شود؛ بعد از {{ s.sources_health.disable_after_failures }} خطای پیاپی غیرفعال می‌شود و هفته‌ای یک بار دوباره امتحان می‌شود.
- **کیفیت:** منبعی که میانگین کیفیتش زیر {{ s.sources_health.low_quality_avg }} یا نرخ قبولی‌اش زیر {{ (s.sources_health.min_acceptance * 100)|round|int }}% باشد، 30 روز متوقف می‌شود.

## انتخاب مطالب و لیدربورد

| مرحله | معیار عبور |
| --- | --- |
| غربال اول | ارتباط با مارکتینگ حداقل {{ s.selection.min_relevance }} و کیفیت حداقل {{ s.selection.score_threshold }} از 10 |
| غربال دوم | ارتباط محوری حداقل {{ s.review.min_relevance }} و کیفیت حداقل {{ s.review.min_quality }}؛ در موارد مرزی رد |

**امتیاز نهایی:** `0.35 × ارتباط + 0.65 × کیفیت + اثر ردهٔ منبع`

**انتخاب هر نوبت:** بهترین مطلب هر دسته، سپس حداقل {{ s.selection.min_tutorials }} آموزش عملی، سپس بالاترین امتیازها. از هر منبع حداکثر {{ s.selection.max_per_source }} مطلب. مطلبی که یک بار آمده، دوباره نمی‌آید. کیفیت بر تعداد مقدم است و آستانه برای پر کردن تعداد پایین نمی‌آید.

**لیدربورد:** {{ s.leaderboard.size }} مطلب برتر هر دسته، با امتیاز حداقل {{ s.leaderboard.min_score }} و فقط از ردهٔ 1 و 2. مطلب تازه در مقایسهٔ مستقیم با فهرست فعلی سنجیده می‌شود و فقط اگر واقعاً برتر باشد وارد می‌شود. لینک‌های مرده هفتگی حذف می‌شوند.

## نگهداری و اعمال تغییرات

همهٔ تنظیمات در پوشهٔ `config` ریپو هستند و از خود GitHub ویرایش می‌شوند (باز کردن فایل، آیکون مداد، Commit). این راهنما هم در `config/guide.md` است و اعداد آن خودکار از تنظیمات خوانده می‌شوند.

| تغییر | محل |
| --- | --- |
| افزودن، حذف یا تغییر ردهٔ منبع | `config/sources.yaml` (`name`، `url`، `hint`، `tier`، `why`) |
| تعریف موضوعات مارکتینگ و توصیف تیم | `scope` و `audience` در `config/settings.yaml` |
| تعداد مطالب، آستانه‌ها، لیدربورد، قواعد منابع | `config/settings.yaml` |
| گیرندگان ایمیل | Secret با نام `MAIL_TO` در Settings ریپو |

## محدودیت‌ها و پرسش‌های رایج

- **قضاوت AI:** امتیازها و بریف‌ها قضاوت AI هستند و صددرصد بی‌خطا نیستند؛ برای تصمیم‌گیری، منبع اصلی مرجع است.
- **متن کامل:** برخی سایت‌ها مثل Medium، HBR و McKinsey دانلود متن کامل را مسدود می‌کنند و بریف آن‌ها از چکیده ساخته می‌شود.
- **arXiv:** مقالات arXiv پیش‌انتشار و داوری‌نشده‌اند.
- **چرا کمتر از {{ s.selection.target_articles }} مطلب تازه؟** آستانهٔ کیفیت پایین نمی‌آید و جای خالی با مطالب نوبت‌های قبل پر می‌شود.
- **چرا یک مطلب معروف نیامده؟** یا منبعش در فهرست نیست، یا از غربال دوم عبور نکرده، یا سهم آن منبع پر شده است.
- **ایمیل نرسید؟** پوشهٔ Spam بررسی شود.
